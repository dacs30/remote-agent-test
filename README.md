# Remote Agent Test

A responsive static web app showcasing capabilities of the owner's guarded remote coding agent. Five interactive examples cover website creation, project exploration, code improvements, validation preparation, and publishing preparation.

Open `index.html` in a browser. No dependencies or build step are required. Select each capability with a mouse or keyboard to change the example. Without JavaScript, the first example and a summary remain available.

- `index.html`: page structure and initial example.
- `styles.css`: blue header, responsive layout, and focus styles.
- `script.js`: local capability selection using text-only DOM updates.

This is an illustrative showcase, not a connected agent interface. It makes no network requests and collects no messages or credentials.

## Publishing

Serve these files from the root of a GitHub Pages site. Publishing through the owner bridge requires a prepared publishing plan and the human's `/confirm` Telegram message. The agent cannot approve publishing. Builds and tests, if requested, require a separate prepared plan and human `/confirm-build` approval.
